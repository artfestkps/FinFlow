Multi-Device Sync Setup Required in Firebase

Firebase blocked multi-device sync because your Firestore Security Rules are not enabled yet. Without this, your friends cannot see the group or splits on their phones.

👉 Go to Firebase Console ➔ Firestore Database ➔ Rules tab and replace the rules with this: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /shared_groups/{allPaths=**} {
      allow read, write: if request.auth != null;
    }
  }
}
